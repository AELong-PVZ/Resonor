1. 基础语法与指令

Resonor 采用极其极简的纯文本记谱法，直接输入即可发声。

音符与休止

  • 基本音符： 1 到 7 代表 do, re, mi, fa, sol, la, si。连续输入 123 代表三拍。
  • 休止符： .（英文句号）代表空拍。例如 1.2 代表第一拍发声，第二拍空，第三拍发声。

八度控制

  • 在数字前加 + 升高一个八度，加 - 降低一个八度。可以叠加使用。
  • 例如：+1 是高音 do，++1 是倍高音 do，-5 是低音 sol。

和弦与连音

  • 用括号 () 将音符括起来，代表同时发声（和弦），且自动占一拍。
  • 例如：(135) 代表 1、3、5 三个音同时响。

力度控制（动态）

  • 音符后紧跟 ^[1-127] 即可指定发声力度（MIDI 力度）。
  • 例如：1^[127] 是爆音强度的 do，1^[20] 是极弱的 do。
  • 不加标记时，默认力度为 90。
  • 若标记和弦整体力度，写在括号外，如 (135)^[100]。

🥁 专属架子鼓映射

当音色选为“架子鼓”时，数字映射会发生改变：

1底鼓 (Kick)
2军鼓 (Snare)
3闭合踩镲 (Hi-hat)
4开踩镲 (Open Hat)
5中嗵鼓 (Mid Tom)
6落地嗵鼓 (Floor Tom)
7强音镲 (Crash)

2. 软件操作详解

🎛️ 顶部控制栏

  • 主题切换： 切换浅色/深色模式，或跟随系统。
  • 极速打字： 开启后，输入长文本时会延迟渲染高亮，大幅降低手机卡顿。可从左上角菜单 → 视图 → 极速打字切换。
  • BPM (速度)： 控制每分钟的拍数。数值越大，播放越快。
  • ×4 兼容： 解决某些老曲谱的 BPM 算法差异，默认开启即可。
  • 节拍器： 播放时伴随“哒哒”声，重拍在第一拍。
  • 主音量： 控制整个软件的总输出音量。

⌨️ 虚拟悬浮键盘

  • 开启与关闭： 点击输入框即可弹出。点击键盘右上角的 × 关闭，点击 + / - 缩放大小。
  • 拖拽： 按住键盘顶部的“虚拟键盘”文字区域，可以随意拖动位置。如果拖出屏幕外，松手会自动吸附回边缘。
  • C / V： 复制选中的文本 / 粘贴文本（无需调用手机系统键盘）。
  • < / >： 将光标向左 / 向右移动一个字符。
  • () / ^[]： 快速输入括号和力度标记，光标会自动居中，方便你直接填入内容。
  • |： 小节线，用于视觉上划分拍子，不影响发声。

🎚️ 混音台 (Mixer)

在左侧列表选中一个乐器后，这里会出现它的专属推子：

  • 音量： 控制该乐器的响度。
  • 声像 (Pan)： 控制声音从左边喇叭还是右边喇叭出。勾选“自动”后，高音会自动偏右，低音偏左，模拟真实交响乐队的摆位。
  • 混响 (Reverb)： 模拟音乐厅的空间回音。
  • 合唱 (Chorus)： 制造类似多件乐器齐奏的宽阔感。
  • 亮度 (Bright)： 控制高频。数值越大，声音越亮、越尖锐。
  • 共振 (Resonance)： 强调声音的特定频段，增加金属感或厚度。

🎵 音轨列表 (Tracks)

  • 这里会列出你当前乐谱中用到的所有乐器。
  • 你可以为不同的音符分配不同的乐器（例如第一拍用钢琴，第二拍用鼓）。
  • 点击列表上方的下拉框，可以搜索并随时更换当前选中的乐器。

🎬 专注预览与导出

  • 专注预览： 隐藏所有编辑界面，全屏大字显示乐谱，并伴随光标跳动，适合用来检查。可从左上角菜单 → 视图 → 专注预览打开。
  • 导出 WAV/MP3： 将你的乐曲录制为音频文件，保存在手机 Download/Resonor 文件夹中。

3. 创作与编曲 (彩蛋？)

既然打开了 Resonor，不妨顺便偷学一点音乐制作的门道，这会让你的曲子瞬间提升一个档次。这里没有枯燥的教科书，只有能直接用的实战经验。

🎵 1. 怎么写出“洗脑”的旋律？

旋律好听的秘诀不是音越多越好，而是“重复 + 微调”。比如写了一段 1234，下一句就可以稍微改个尾音变成 1235。这叫动机发展。不要东写一个音、西写一个音，记住：“好听 = 熟悉感 + 一点点新鲜感”。

🎹 2. 和弦套路：直接抄作业

不用去背复杂的和弦推导，流行乐有四大“万能公式”，你直接用括号把它们框起来，铺在背景里就行：

  • 万金油走向（卡农）： (135) (572) (461) (246)，非常抒情。
  • 流行抒情走向： (461) (572) (135)，经典流行歌标配。
  • 悬念走向： 把主和弦改成 (246)（小和弦），立刻忧郁起来。

⏱️ 3. 节奏的灵魂：留白与切分

不要把每一拍都塞满！用 . 留出空拍，会让你有一种“呼吸感”。比如 1.2.3 就比 123 听起来有跳跃感。试着把重音错开，比如 ..12（抢拍），这就是现代流行乐里常说的“律动感”（Groove）。

💥 4. 动态控制：力度是情绪的放大器

平铺直叙的歌像念经。试试用 ^[] 制造起伏。比如 1^[127]（重）和 1^[40]（轻）交替。同样的旋律，如果你在第一拍重、后面几拍轻，听起来就会有“强弱次强弱”的律动。

🎚️ 5. 混音台：拉开空间感

为什么你的歌听起来糊成一团？因为乐器全挤在中间。去左侧混音台：

  • 声像 (Pan)： 把钢琴拉左边，把吉他拉右边，声音立刻“开阔”了。
  • 低切/厚度： 如果主旋律和贝斯打架，把主旋律的“厚度”稍微降一点，让贝斯去负责低音区。

🎸 6. 简单粗暴的“配器”法则

不要所有乐器都弹一样的音符。正确的分工是：

  • 选个“贝斯”或者“低音”乐器，只弹 -1 -5 这种长音铺底。
  • 选个“弦乐”或“合成器”，弹 (135) 这种和弦做背景。
  • 选个“长笛”或“主音吉他”，在上面弹你的 1234 主旋律。

把高、中、低频交给不同的乐器，这才是专业编曲的秘诀。
